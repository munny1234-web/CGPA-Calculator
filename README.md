# CGPA Calculator

An Android app that helps university students track courses, calculate their CGPA semester by semester, and see how their results change over time. Built with **Kotlin** and **Jetpack Compose**.

## ✨ Features

- **Semester-wise course management:** add, edit and group courses by semester
- **Smart import:** bring in courses from CSV, PDF, or a photo of a result sheet (OCR)
- **PDF transcript export** to save or share results
- **CGPA trend charts** and analytics
- **Biometric lock** to keep results private
- **English / Bangla** language switching instantly inside the app
- **Firebase Authentication** with separate data for each user

## 🛠️ Tech Stack

| Part | Technology |
|---|---|
| Language | Kotlin |
| UI | Jetpack Compose, Material Design |
| Auth | Firebase Authentication |
| Storage | SharedPreferences (per user) |
| Other | OCR, PDF generation, biometric authentication |

## ⚙️ How to Run

1. Clone this repository and open it in Android Studio.
2. Add your own `google-services.json` from Firebase to the `app/` folder.
3. Sync Gradle and run the app.
